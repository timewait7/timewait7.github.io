  • Docs
  • 项目实战

性能验证三件套：压测找拐点、并发调优、JVM 定位。

学习路径

前置要求：架构与数据篇（见 Zeus-Doc 架构与数据导航）；Java 并发与 JVM 概念（见 Java 导航）。

推荐顺序：压测 → 并发设计 → JVM 定位。压测回答「性能拐点在哪」（JMeter 阶梯加压、Tomcat 调优验证），并发回答「热点代码怎么写」（隔离线程池、拒绝策略、并行聚合、读写锁），JVM 回答「内存问题怎么查」（GC 日志、G1 vs CMS、MAT 泄漏链）。
