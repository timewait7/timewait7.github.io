MySQL 关系型数据库专题导航：后端能力链第 3 阶段，面试权重最高的单点技术。

学习路径

前置要求：Java 基础；能写基础 SQL。

推荐顺序：原理（索引/事务/锁）→ SQL 优化 → 高可用与分库分表。原理决定「能不能答深」，优化决定「生产能不能扛」，高可用与分库分表是架构师向的深挖方向。

  • 原理与优化：InnoDB 架构、索引 B+ 树、事务隔离与 MVCC、锁、SQL 优化
  • 高可用与分库分表：主从复制、高可用方案、分库分表落地
  • InnoDB 深入（建设中）：Buffer Pool、redo/undo log 细节
