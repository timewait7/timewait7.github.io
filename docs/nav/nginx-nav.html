Nginx 反向代理与 Web 服务器专题导航：后端能力链第 7 阶段，流量入口的承载层。

学习路径

前置要求：Linux 基础（见 Linux 导航）；HTTP 概念（见 计算机网络导航）。

推荐顺序：反向代理与负载均衡 → 静态资源与缓存 → 高可用。反向代理回答「流量怎么分发」（四层/七层、负载均衡策略），静态与缓存回答「Web 资源怎么高效地出」，高可用回答「Nginx 自己挂了怎么办」（Keepalived）。
