系统设计专题导航：后端能力链第 6 阶段，把全链知识组装成「架构设计」答案。

学习路径

前置要求：后端能力链前 5 阶段（数据库/缓存/消息/分布式），设计题是它们的综合运用。

推荐顺序：方法论 → 秒杀案例 → 短链案例 → 三大设计主题。方法论回答「拿到设计题怎么走流程」（需求澄清 → 容量估算 → 架构 → 详设 → 权衡），秒杀案例是「写」场景完整落地（一题串起限流/缓存/削峰/防超卖/降级），短链案例是「读」场景完整落地（缓存分层/布隆过滤器/301vs302/热点防护），三大主题是常考落点：高性能、高可用、熔断限流降级（具体机制已并入两个案例正文）。

  • 方法论：设计流程、容量估算、评估与权衡
  • 秒杀案例（写场景）：限流/削峰/防超卖/对账/降级
  • 短链案例（读场景）：发号器/62 进制、64 表分表、布隆过滤器、301vs302、热点防护
  • 高性能 / 高可用 / 熔断限流降级：机制已并入案例正文（见各子导航页跳转说明）
