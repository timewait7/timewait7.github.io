  • Docs
  • AI 学习

本文是本站 AI 专题知识体系的导航枢纽 + 概念速查。AI 内容已按”概念 → 应用 → 工程化 → 项目”拆分为 20 篇文章，本文只做三件事：

  1. 学习路线图（第 1 节）：按人群给出学习路径、时间分配与阶段交付物。
  2. 专题导航（第 2~6 节）：按分组链接到各文章，标注覆盖范围与重点章节。
  3. 概念速查（附录）：AI 高频概念按”一句话定义 → 详见某文”整理，查阅用。

建议搭配 博客导航（全站总索引）与 Java 后端面试体系（Java 主线）一起使用。

A. 模型与调用

概念 一句话 详见
token 模型计费与窗口的最小单位，中文约 1.5~2 字/token LLM API与工具调用实战
上下文窗口 单次请求能”看到”的信息上限，超限需裁剪 同上
temperature 输出随机性（02），调试固定 0，生产按场景 0.30.8 Prompt工程实战
流式输出（SSE） 逐 token 推送，首 token 毫秒级到达，对话产品标配 LLM API与工具调用实战
结构化输出 JSON Mode/JSON Schema 保证输出可解析，配合修复循环 同上
Function Calling 模型申请调工具（不执行），代码执行后回填结果 同上
Token 计费 输入+输出分别计价，缓存命中输入价降至约 1/10 同上

B. 知识增强

概念 一句话 详见
Embedding 文本 → 稠密向量，语义相近向量距离近 RAG原理与实践
向量检索 相似度 Top-K 召回，ANN 索引保性能 向量数据库原理与实践
混合检索 BM25 关键词 + 向量语义双路召回，RRF 融合 RAG原理与实践
Rerank 粗召回 50 条 → Cross-Encoder 精排 5 条，命中率 +5~15% 同上
RAG 先检索再生成，知识归 RAG、行为归微调 同上
幻觉 模型编造事实，防幻觉三件套：指令约束/引用溯源/评测 LLM评测与可观测性

概念 一句话 详见
Workflow 预编排固定链路，控制权在代码 Agent原理与实践

D. 推理与训练

概念 一句话 详见
Prefill/Decode 输入一次性并行处理 + 输出逐 token 自回归 LLM推理与部署实战
