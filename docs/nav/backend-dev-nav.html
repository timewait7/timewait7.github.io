后端开发面试导航

  • Docs
  • 后端开发

后端开发方向的能力链路线图：语言 → 框架 → 数据存储 → 中间件 → 分布式与微服务 → 系统设计 → 部署运维。本页负责「为什么按这个顺序学、每块学到什么程度」，各组的文章入口在左侧菜单逐层展开。

阅读总纲

后端能力链的依赖关系决定了学习顺序：先有语言，才能谈框架；先理解单机存储，才能理解分布式；中间件（消息、RPC、协调）是分布式的具体零件；最后用系统设计与部署运维把整套体系装进生产环境。面试权重：语言（并发/JVM）与数据存储（MySQL/Redis）最高，各占约 25%；中间件与分布式约占 30%；框架、系统设计、部署运维约 20%。

阶段 能力 读完能做什么
1 Java 语言与 JVM 说清并发的可见性/原子性/有序性，能回答 JVM 调优与 OOM 排查
2 框架 讲清 Spring 核心机制与 MyBatis 原理，不再停留在会用
3 数据存储 覆盖 MySQL 索引/事务/锁与分库分表、Redis 缓存三兄弟
4 中间件 消息不丢不重、RPC 与协调组件的工作机制
5 分布式与微服务 把分布式理论与微服务治理串成一张网
6 系统设计 面对开放题有方法论：评估、拆解、权衡、演进
7 部署运维 容器化与云原生技能落地，能独立搭建与排障

Java（语言与 JVM）

Java 是整条能力链的语言地基。推荐顺序：核心基础 → 并发编程 → JVM 调优 → 开发速查（速查边用边查，无顺序要求）。面试权重：并发最高（线程池、锁、JMM 是必考点），JVM 次之（GC、OOM 排查）。速查表面向日常开发，不面向面试。

入口：Java 导航 · 面试体系总枢纽：Java 后端面试体系

框架

框架层解决「业务代码怎么组织」：Spring 是核心（IoC/AOP 与 MVC 机制），MyBatis 管数据访问，Tomcat 承载 Web 容器。推荐顺序：Spring → MyBatis → Tomcat，三者递进：先懂容器管理，再看数据访问，最后理解 Web 服务器。面试权重：Spring 最高（Bean 生命周期、循环依赖、事务传播），MyBatis 次之。

入口：Spring 导航 · MyBatis 导航 · Tomcat 导航【建设中】

数据存储

数据落盘与读取的三大件：关系型（MySQL）、缓存（Redis）、搜索（Elasticsearch）。推荐顺序：MySQL → Redis → Elasticsearch：先掌握关系型的地基（索引、事务、锁），再理解缓存与搜索是对读路径的补充。面试权重：MySQL 最高（索引/事务/锁/分库分表），Redis 次之（缓存三兄弟、持久化、集群），ES 主要面场景题。

入口：MySQL 导航 · Redis 导航 · ElasticSearch 导航

中间件

消息队列、RPC 与协调组件是分布式系统的零件库。推荐顺序：先 Kafka/RocketMQ（消息语义：不丢不重、顺序、事务消息）→ Netty（网络通信底层，理解消息与 RPC 的传输基础）→ Dubbo（RPC 框架）→ ZooKeeper（协调服务，可与分布式章节对照）。面试权重：消息队列最高（丢消息/重复消费/顺序/堆积四连问），Netty 次之（线程模型、零拷贝），Dubbo 与 ZooKeeper 主要面深挖。

入口：Kafka 导航 · RocketMQ 导航 · Netty 导航 · Dubbo 导航 · ZooKeeper 导航

分布式与微服务

分布式理论回答「多机器协作下的正确性」：一致性、共识、分布式事务、幂等与补偿；微服务回答「如何组织大规模协作」：注册发现、配置中心、网关与治理。推荐顺序：先分布式理论 → 再微服务架构：没有理论地基，微服务的每个组件都是黑盒。面试权重：CAP/BASE、分布式事务（TCC/Seata）、幂等与补偿必考；微服务侧重 Spring Cloud Alibaba 组件职责与调用链。

入口：分布式导航 · 微服务导航

系统设计

系统设计是把前面所有能力用于解决真实问题的方法论层：需求评估 → 容量估算 → 架构拆解 → 权衡取舍 → 演进路径。推荐顺序：先方法论（读 1 篇）→ 按主题深入（高性能/高可用/熔断限流降级）。面试权重：开放题占比高（秒杀、短链、消息推送），方法论 + 面试官追问的应变能力。

入口：系统设计导航（方法论已就绪，高性能/高可用/熔断限流降级【建设中】）

部署运维

把代码装进生产环境的能力：容器化（Docker）→ 容器编排（Kubernetes）→ 承载层（Nginx）→ 操作系统基础（Linux）。推荐顺序：Linux → Docker → Kubernetes → Nginx：先有系统操作能力，再逐层理解容器与编排。面试权重：项目相关度高，常见于「你怎么部署/排查」类追问。

入口：Docker 导航 · Kubernetes 导航 · Linux 导航 · Nginx 导航

相关基础（地基）

计算机基础是整条能力链的地基，不属于某一段：操作系统的内存/并发/IO 模型支撑 JVM 与 Netty；计算机网络的 TCP/IP/HTTP 支撑 MySQL 主从、消息队列与 RPC；数据结构与算法支撑索引、缓存与系统设计。建议：在能力链推进过程中按需回补——学并发时回看 OS 并发章节，学 Netty 时回看网络与 IO 模型。

入口：计算机基础导航（操作系统/计算机网络/数据结构与算法【建设中】）
