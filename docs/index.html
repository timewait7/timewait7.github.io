关于这个博客

这里没有碎片化的「速通」与「收藏即学会」。每一篇文章都沿同一标准写成：原理先行，实践落地——先讲清它为什么是这样，再给出可以直接复用的代码、配置与踩坑记录。

全部内容围绕一个真实的技术主线组织：一名 Java 后端工程师，如何把基础打牢、把系统做大、再走向 AI 工程化。

内容版图

后端开发 —— 博客的主干线。一条完整的后端能力链：Java 核心（集合、并发、JVM）→ 主流框架（Spring、MyBatis、Tomcat）→ 数据存储（MySQL、Redis、Elasticsearch）→ 中间件（Kafka、RocketMQ、Dubbo、Netty、ZooKeeper）→ 分布式与微服务 → 系统设计 → 部署运维（Nginx、Docker、Kubernetes、Linux）。适合作为后端知识体系的复习地图。

计算机基础 —— 操作系统的内存与并发、计算机网络的传输与协议、数据结构与算法。地基板块，正在建设中。适合查漏补缺、补齐科班知识。

AI 学习 —— 面向后端工程师的 AI 转型路线，按「学习路径与概念 → AI 应用开发 → AI 工程化 → 项目实战与案例」四组递进：从大模型核心概念，到 LLM API、RAG、Agent、MCP、微调与评测，全部以 Java 技术栈落地。适合从零转型 AI 工程化方向。

项目实战 —— 一个贯穿全书的具体项目：Zeus-Doc。围绕它的真实演进，拆出架构与数据、性能与并发、开发运维、面试实战四组复盘，另有独立的《项目面试准备指南》。适合学习「面试怎么讲项目」。

Misc —— 认知与方法论（效率、思维、复盘），以及开发工具手册（版本控制、构建、IDE、语言、命令行、文档绘图）。适合随手翻阅、持续累积。

随笔·生活 —— 工作之外、生活之内的沉淀：理财、阅读笔记与感想随笔。正在建设中，有内容会逐步填充。适合沉淀技术之外的热爱。

三条阅读路线

  • 面试冲刺：从 后端开发面试导航 走主线，以 项目面试准备指南 收尾——先有体系，再谈应答。
  • AI 转型：从 AI学习体系导航 的「学习路径与概念」起步，按四组顺序推进，每组之间互为前置。
  • 深度进修：按内容版图的任意一条链（存储、中间件、部署）逐篇深入，文章末尾的「相关文章」已串好前驱与后继。

写作信条

  • 实战优先：每篇问题均来自真实场景——线上故障、面试追问、项目重构，而不是教材例句。
  • 体系化：文章之间互相引用、互相承接，导航即地图，地图即知识图谱。
  • 持续演进：本文档与目录随内容同步生长；「建设中」的板块会逐步补齐。
