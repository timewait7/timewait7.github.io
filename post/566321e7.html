高频操作场景（快捷键背后的目的）

快捷键不是背的，是「场景触发」的——遇到下面这些情况，直接按对应键：

场景 快捷键（Mac） 说明
改名后全项目引用一起改 ⇧+F6（Rename） 变量/方法/文件改名，选「Search in comments」连注释一起改
跳转定义 / 看调用方 ⌘+点击 / ⌥+F7（Find Usages） 读别人代码最快的路径：先跳定义，再看谁调用了它
快速找文件 / 类 / 符号 ⇧⇧（Search Everywhere） 不记得路径就搜名字，比在目录里翻快一个数量级
查看当前文件改动历史 ⌃+V（Local History） 没有 Git 提交过的改动也能恢复，误删代码的第一救星
格式化 / 整理 import ⌥+⌘+L / ⌃+⌥+O 提交代码前必做，diff 里全是格式噪音的元凶
重构提取方法 / 变量 ⌥+⌘+M（Extract Method）/ ⌥+⌘+V 长方法拆分与魔法值提取，比手动改安全（自动更新调用处）
调试：加断点看变量 行号左侧点击，⌥+F8 求值 断点调试比打印日志省事；条件断点（右键设置）只在目标数据出现时停
调试：方法调用栈回溯 ⌘+F8 断点 → 看 Frames 面板 排查「谁调进来的」，比看代码快
智能补全 / 生成代码 ⌃+⇧+空格（Smart Complete）/ ⌘+N（Generate） 生成 getter/setter、构造器、equals/hashCode，别手敲
多光标批量改 ⌥+鼠标拖动 / ⌥+⌘+G（Select All Occurrences） 同名字段批量重命名、批量加前缀，替代逐行手改

使用场景组合示例：

  • 接手一段陌生代码：⇧⇧ 找入口 → ⌘+点击 跳定义 → ⌥+F7 看调用方 → ⌘+⌥+← 返回上一步——10 分钟理清调用链。
  • 改一个字段名：⇧+F6 改名（全项目引用自动更新）→ ⌘+B 看编译错误 → ⌥+⌘+L 格式化收尾——不出现一次「改漏引用」。
  • 线上 bug 排查：⌘+F8 打断点 → 条件断点卡住异常数据 → ⌥+F8 求值看变量 → Frames 面板回溯调用栈——比加 20 行日志快。

原理与调试技巧深挖见 Java 并发编程（多线程调试断点）与 Zeus-Doc 排障实战复盘（线上排查方法论）。
