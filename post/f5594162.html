日常运维高频命令实战手册

Posted on 2026-08-22 In 部署运维 Word count in article: 4.7k Reading time ≈ 17 mins.

1. 系统信息与性能排查

1.1 高频命令

命令 用途
uptime 查看系统负载、运行时长、登录用户数
top -c / htop 实时查看进程 CPU、内存占用，-c 显示完整命令行
vmstat 1 5 查看 CPU、内存、IO、上下文切换，每秒 1 次共 5 次
iostat -xz 1 查看磁盘 IO 使用率、等待时间、吞吐量
mpstat -P ALL 1 查看每个 CPU 核心的使用率
free -h 查看内存和 Swap 使用情况
sar -n DEV 1 查看网卡流量、错误包
dmesg | tail -20 查看内核日志，判断硬件或 OOM 问题
lscpu / lsblk 查看 CPU 架构 / 块设备信息
nproc 查看 CPU 核数

1.2 生产实践案例

场景：业务反馈服务器卡顿，页面打开缓慢。

处理结果：发现是某个定时任务与业务高峰叠加，临时降低任务频率，并优化了代码中的死循环。

2. 文件与磁盘管理

2.1 高频命令

命令 用途
df -hT 查看磁盘分区使用率及文件系统类型
du -sh /* 统计根目录下各目录大小，快速定位大目录
du -h --max-depth=1 /var 按层级查看目录占用
ls -lht /var/log 按时间倒序列出文件大小
find / -type f -size +100M -mtime -7 查找最近 7 天修改的 100M 以上文件
stat /path/file 查看文件详细属性、时间戳
lsof +L1 查找已被删除但仍被进程占用的文件
lsattr / chattr 查看/设置文件隐藏属性，防止误删
rsync -avz src/ dest/ 高效同步文件/目录
tar -czvf backup.tar.gz /path 打包压缩
tar -xzvf backup.tar.gz -C /target 解压到指定目录
dd if=/dev/zero of=test.img bs=1M count=100 生成测试文件或测试磁盘写速度
blkid / mount 查看块设备 UUID 和挂载信息
fdisk -l 查看磁盘分区表

2.2 生产实践案例

场景：监控告警服务器磁盘使用率达到 95%。

处理结果：日志文件被 logrotate 正常切割，磁盘使用率降至 60%，并配置了告警阈值。

3. 网络诊断与配置

3.1 高频命令

命令 用途
ip addr / ip link 查看网卡 IP、MAC、状态
ip route 查看路由表
ss -tulnp 查看监听端口及对应进程
ss -s 查看连接统计
ss -tnp 查看 TCP 连接及进程
ping -c 4 <host> 测试网络连通性
traceroute <host> 路由追踪
mtr <host> 动态路由追踪，结合 ping 和 traceroute
nslookup <domain> / dig <domain> DNS 解析排查
curl -Iv https://<domain> 查看 HTTP 握手及响应头
wget --spider <url> 测试 URL 是否可访问
tcpdump -i eth0 port 443 -s0 -w /tmp/https.pcap 抓取 HTTPS 流量
nmap -sT -p 1-1000 <ip> 扫描开放端口
ethtool eth0 查看网卡速率、双工模式
firewall-cmd --list-all 查看 firewalld 配置
iptables -L -n -v 查看 iptables 规则

3.2 生产实践案例

场景：用户反馈无法访问线上 HTTPS 服务，域名解析正常。

处理结果：防火墙规则遗漏导致，放行后服务恢复。后续将防火墙配置纳入变更审核流程。

4. 用户与权限

4.1 高频命令

命令 用途
useradd -m -s /bin/bash username 创建用户并指定 shell
usermod -aG wheel username 将用户加入附加组
userdel -r username 删除用户及 home 目录
groupadd / groupmod 组管理
passwd username 设置用户密码
chage -l username 查看用户密码过期策略
id username 查看用户 UID、GID 及所属组
who / w 查看当前登录用户
last / lastb 查看成功/失败登录记录
su - username 切换用户并加载环境变量
sudo -l 查看当前用户可执行的 sudo 命令
visudo 安全编辑 sudoers
chmod 755 file 修改文件权限
chown user:group file 修改文件属主属组
chgrp group file 修改文件属组
umask 022 设置默认权限掩码
setfacl -m u:user:rwx file 设置 ACL 权限
getfacl file 查看 ACL 权限
lsattr / chattr +i file 文件隐藏属性，+i 禁止修改删除

4.2 生产实践案例

场景：新入职同事无法读取 Web 目录 /data/www，导致无法部署代码。

处理结果：通过组 + ACL 灵活授权，同时限制 sudo 权限范围，满足最小权限原则。

5. 进程与服务管理

5.1 高频命令

命令 用途
ps -ef / ps aux 查看所有进程
pstree -p 树状显示进程关系
pgrep -f nginx 按名称查找进程 PID
pidof nginx 快速获取进程 PID
top -Hp <pid> 查看进程内线程
systemctl status <service> 查看服务状态
systemctl start/stop/restart/reload <service> 管理系统服务
service <name> start SysV 风格服务管理
kill -15 <pid> / kill -9 <pid> 优雅终止 / 强制杀死
killall <name> / pkill -f <pattern> 按名称终止进程
nohup command & 后台运行并忽略 HUP 信号
setsid command & 在新会话中运行
disown -h %1 将作业从当前 shell 移除
jobs / bg / fg 作业控制

5.2 生产实践案例

场景：Nginx 频繁返回 502，检查发现 worker 进程不断退出。

处理结果：后端 PHP-FPM 进程数不足导致 Nginx 502，扩容后服务恢复。后续增加 PM 监控。

6. 日志分析与审计

6.1 高频命令

命令 用途
journalctl -u <service> -n 100 --no-pager 查看服务日志
tail -f /var/log/messages 实时跟踪日志
head -50 file 查看文件头部
less +F file 分页查看并支持实时跟踪
grep -n -A 5 -B 5 "ERROR" file 搜索关键词并显示前后文
awk '{print $1, $NF}' access.log 按列提取日志字段
sed -n '100,200p' file 查看指定行范围
sort / uniq -c 排序 / 统计重复次数
wc -l 统计行数
cut -d' ' -f1 按分隔符提取列
tee -a file 追加并输出到屏幕
logger "message" 向 syslog 写入日志
multitail -f file1 file2 同时跟踪多个日志文件
logrotate -d config 日志切割调试

6.2 生产实践案例

场景：API 接口出现大量 5xx 错误，需要快速定位问题接口。

处理结果：定位到 /api/v1/orders 接口因数据库慢查询导致超时，优化索引后 5xx 下降为 0。

7. 包管理与软件部署

7.1 高频命令

命令 用途
apt update && apt upgrade Debian/Ubuntu 更新源并升级
yum update / dnf update RHEL/CentOS 升级
apt install <pkg> / yum install <pkg> 安装软件
apt remove <pkg> / yum remove <pkg> 卸载软件
rpm -qa --last 查看最近安装的 RPM 包
rpm -ql <pkg> 列出包安装的文件
rpm -qf /path/file 查看文件属于哪个包
dpkg -l / dpkg -L <pkg> / dpkg -S <file> Debian 包管理
yum history / dnf history 查看事务历史
yum history undo <ID> 回滚某次操作
yum versionlock <pkg> 锁定包版本
snap list / snap install <pkg> Snap 包管理
./configure && make && make install 源码编译安装

7.2 生产实践案例

场景：服务器执行 yum update 后，应用依赖库被升级导致服务异常。

处理结果：通过历史事务回滚快速恢复，并锁定关键包版本，后续升级前先在测试环境验证。

8. 定时任务与自动化

8.1 高频命令

命令 用途
crontab -l / crontab -e 查看/编辑当前用户定时任务
cat /etc/crontab 系统级定时任务
ls /etc/cron.d/ 系统定时任务目录
run-parts /etc/cron.daily 执行目录下所有脚本
anacron -f 执行错过的周期任务
at now + 5 minutes 一次性定时任务
systemctl list-timers 查看 systemd timer
tail -f /var/log/cron 查看 cron 执行日志

8.2 生产实践案例

场景：运维发现数据库备份任务未执行，备份文件停留在 3 天前。

处理结果：修复环境变量问题后备份恢复正常。后续所有定时脚本统一加载 /etc/profile 并输出日志。

9. 安全加固与应急响应

9.1 高频命令

命令 用途
lastb / last 查看失败/成功登录记录
who / w 查看当前在线用户
fail2ban-client status sshd 查看 fail2ban 封禁状态
`ss -tnp grep ESTAB`
firewall-cmd --list-all 查看防火墙配置
iptables -L -n -v 查看 iptables 规则
ufw status verbose 查看 UFW 状态
auditctl -l 查看审计规则
ausearch -m avc -ts recent 查看 SELinux AVC 拒绝日志
find / -perm -4000 -type f 查找 SUID 文件
rkhunter --check / lynis audit system 安全审计工具
ssh-keygen -t ed25519 生成 SSH 密钥
vi /etc/ssh/sshd_config SSH 加固配置

9.2 生产实践案例

场景：安全团队通报服务器存在异常外联行为，怀疑被植入木马。

处理结果：清除木马并加固 SSH，启用 fail2ban，后续接入集中安全审计。

10. 容器与虚拟化常用命令

10.1 高频命令

命令 用途
docker ps -a 查看所有容器
docker logs --tail 100 -f <container> 查看容器日志
docker stats 查看容器资源占用
docker exec -it <container> /bin/bash 进入容器
docker inspect <container> 查看容器详情
docker system df 查看 Docker 磁盘占用
docker network ls / docker volume ls 查看网络/卷
kubectl get pods -n <namespace> 查看 Pod 列表
kubectl get deploy,svc,ingress -n <ns> 查看部署、服务、Ingress
kubectl describe pod <pod> -n <ns> 查看 Pod 详情及事件
kubectl logs <pod> -n <ns> --previous 查看 Pod 上次退出日志
kubectl exec -it <pod> -n <ns> -- /bin/bash 进入 Pod
kubectl top pods -n <ns> 查看 Pod 资源使用
kubectl get events -n <ns> --sort-by=.lastTimestamp 查看事件
kubectl port-forward svc/<svc> 8080:80 -n <ns> 端口转发

10.2 生产实践案例

场景：Kubernetes 中某服务 Pod 频繁重启，服务不稳定。

处理结果：OOM 导致重启，调整内存限制后服务稳定。建议加入 HPA 和资源配额。

11.1 故障现象

某日 15:00 监控同时报警：

  • 磁盘使用率 92%
  • CPU iowait 持续高于 20%
  • 网站首页响应时间超过 5 秒

11.2 排查过程

第一步：全局状态检查

第二步：定位磁盘占用

第三步：处理 Nginx 日志

第四步：处理 MySQL binlog

第五步：分析慢查询

第六步：网络与连接检查

第七步：验证恢复

11.3 总结与沉淀

问题 根因 解决方案
磁盘告警 Nginx 日志未切割、MySQL binlog 过期时间过长 修复 logrotate、调整 expire_logs_days
响应慢 磁盘 IO 打满 + 慢查询 清理磁盘、添加索引
TIME_WAIT 多 内核参数不合理 优化 TCP 参数

后续改进：

  • 配置 logrotate 并纳入监控
  • MySQL binlog 保留 7 天
  • 慢查询告警
  • 容量规划和磁盘使用率告警阈值提前到 80%

结语

运维命令是基础，但更重要的是排查思路和沉淀机制。本文按照日常高频场景分类整理，每个案例都来自生产实践，希望能帮助你快速定位和解决问题。建议将常用命令整理成自己的“运维手册”，并定期更新。

注意：生产环境执行操作前，请务必确认影响范围并做好备份。
