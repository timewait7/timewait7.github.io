文本处理三剑客：grep、sed、awk

Posted on 2025-01-08 In 开发工具 Word count in article: 8k Reading time ≈ 29 mins.

1. 概述：三个工具的定位

Linux 文本处理三剑客 grep、sed、awk，分工一句话：

工具 定位 一句话
grep 搜索 在文本中查找匹配的行，只读不改
sed 编辑 流式编辑，按行读入并执行增、删、改、替换
awk 数据处理 按分隔符切分字段，支持变量、数组与流程控制，擅长统计和格式化

一句话区分：要找出哪些行，用 grep；要改动哪些行，用 sed；要对行内的字段算账，用 awk。 三者经常通过管道串联使用，例如 grep ERROR app.log | awk '{print $2}' | sort | uniq -c，grep 负责筛选、awk 负责计算、sed 负责排版。

2.1 基本语法与常用选项

grep 从文件或标准输入中逐行读取文本，按模式匹配每一行，将匹配的行输出到标准输出：

常用选项：

选项 说明
-i 忽略大小写
-v 反向匹配，输出不匹配的行
-r / -R 递归搜索目录（-R 会跟随符号链接）
-l / -L 只输出包含 / 不包含匹配内容的文件名
-n 显示匹配行的行号
-c 只统计匹配的行数
-A n 输出匹配行及其后 n 行（after）
-B n 输出匹配行及其前 n 行（before）

grep 的退出码在脚本中很有用：0 表示有匹配，1 表示无匹配，2 表示出错。

2.2 正则表达式速查

grep 默认使用基础正则表达式（BRE），-E 切换为扩展正则表达式（ERE），-P 使用 Perl 兼容正则（PCRE）。三者的主要差异在于元字符是否需要转义：

语法 基础正则（BRE） 扩展正则（ERE） Perl 正则（PCRE）
或 |（需转义） ` `
分组 \(...\)（需转义） (...) (...)
量词 + ? {n,m} 需转义（\+ 等） 直接使用 直接使用
预定义字符类（\d \w \s） 不支持 不支持 支持
懒惰匹配（.*?） 不支持 不支持 支持

常用元字符：

元字符 含义
. 匹配任意单个字符
* 前面的字符重复 0 次或多次
+ 前面的字符重复 1 次或多次（ERE/PCRE）
? 前面的字符出现 0 次或 1 次（ERE/PCRE）
^ / $ 行首 / 行尾锚定
[...] 字符集，如 [0-9]、[a-zA-Z]、[^0-9]（取反）
\(...\) / (...) 分组捕获
| / ` `
\< / \> 单词首 / 单词尾锚定（BRE）

3. sed

3.1 执行模型

sed 编辑器可以根据命令来处理数据流中的数据，这些命令要么从命令行中输入，要么存储在一个文本文件中。sed 编辑器会执行下列操作：

  1. 一次从输入中读取一行数据。
  2. 根据所提供的编辑器命令匹配数据。
  3. 按照命令修改流中的数据。
  4. 将新的数据输出到 STDOUT 或文件中。

模式空间和保持空间

模式空间（Pattern Space）是当前工作的空间，sed 编辑器会将数据流中文本行读入到模式空间进行处理。保持空间（Hold Space）可以看作是模式空间的备份空间，可以将模式空间的某些行临时存储在保持空间，之后再将这些行从保持空间移回模式空间。

模式空间和保持空间的交互命令如下：

命令 描述
h 将模式空间复制到保持空间
H 将模式空间附加到保持空间
g 将保持空间复制到模式空间
G 将保持空间附加到模式空间
x 交换两个空间的内容

地址

默认情况下，在 sed 编辑器中使用的命令会作用于文本数据的所有行。如果只想将命令作用于特定行或某些行，则必须用行寻址（line addressing）。在 sed 编辑器中有两种形式的行寻址：

  • 以数字形式表示行区间
  • 用文本模式来过滤出行

数字形式行寻址

  • 指定某行：sed '2command' file
  • 指定行区间：sed '2,3command' file
  • 从某行开始到结尾：sed '2,$command' file

文本模式行寻址

  • 匹配某行：sed '/pattern/command' file
  • 匹配行区间：sed '/start/[,/end/]command' file

移动到下一行：n

命令解释：要删除第1行和第3行之间的空白行，需先根据 /header/ 匹配到第1行，再用 n 命令让 sed 编辑器移动到下一行，最后用 d 命令删除空白行。

追加下一行：N

命令解释：小写的 n 命令让 sed 编辑器移动到下一行，大写的 N 命令则是让编辑器将下一行追加到模式空间。因此当匹配到 /first/ 所在的行时，N 命令让 sed 编辑器继续读入下一行，此时模式空间的文本内容是 This is the first data line.\nThis is the second data line.，最后通过 s/\n/ / 命令将换行符替换成空格。该命令呈现出来的效果就是合并两行。

N 命令的一种使用场景是查找并编辑可能分散在多行的短语。

N 命令会把上下两行读入模式空间，并通过换行符 \n 合并成单行文本，所以模式 /System.Administrator/ 就可以匹配到 System\nAdministrator，最后通过 s 命令替换成 Desktop user。

4. awk

gawk 程序是 Unix 中原始 awk 程序的 GNU 版本，其报告生成能力通常用来从大文本文件中提取元素，并将它们格式化成可读的格式，如格式化日志文件。

gawk 的命令格式为：gawk options program file。

常用的选项如下：

选项 说明
-F fs 指定行中划分数据字段的字段分隔符
-f file 从指定的文件中读取程序
-v var=value 定义 gawk 程序中的一个变量及其默认值
-mf N 指定要处理的数据文件中的最大字段数
-mr N 指定数据文件中的最大数据行数
-W keyword 指定 gawk 的兼容模式或警告等级

4.1 执行模型：BEGIN / 主循环 / END

awk 程序由若干条 pattern { action } 规则组成，其执行模型是：读一行 → 匹配规则 → 执行动作，循环往复。除此之外还有两个特殊模式，分别在处理开始前和结束后各执行一次：

  • **BEGIN { action }**：在读取任何输入之前执行一次。通常用于初始化变量、设置 FS 分隔符、打印表头。
  • 主循环：逐行读取输入，对每一行依次匹配各条规则，匹配成功则执行对应的 action。
  • **END { action }**：所有输入处理完之后执行一次。通常用于输出汇总统计结果。

4.2 内建变量与自定义变量

所有编程语言都可以使用变量来存取值，gawk 编程语言支持两种类型变量：

  • 内建变量
  • 自定义变量

数据字段变量

在处理文本时，gawk 会给一行中的每个数据元素分配一个变量：

  • $0：表示整个文本行
  • $1：表示第1个数据字段
  • $n：表示第n个数据字段

分隔符变量

gawk 默认采用空白字符作为输入和输出字段分隔符。

变量 描述
FIELDWIDTHS 由空格分隔的一列数字，定义了每个数据字段确切宽度
FS 输入字段分隔符
RS 输入记录分隔符
OFS 输出字段分隔符
ORS 输出记录分隔符
  • 通过 FS 指定输入字段分隔符
  • 通过 OFS 指定输出字段分隔符
  • 通过 FIELDWIDTHS 变量来匹配数据在记录中的位置

在一些应用程序中，数据并没有使用字段分隔符，而是被放置在了记录中的特定列。这种情况下，必须设定 FIELDWIDTHS 变量来匹配数据在记录中的位置。一旦设置了 FIELDWIDTHS 变量，gawk 就会忽略 FS 变量，并根据提供的字段宽度来计算字段。

  • 通过 RS 指定输入记录分隔符

gawk 默认把换行符作为记录分隔符。当遇到记录跨行存储，不同记录以空白行分隔的文本，就需要通过 RS 指定记录分隔符。

其他内建变量

FILENAME 用作gawk输入数据的数据文件的文件名
IGNORECASE 设成非零值时，忽略gawk命令中出现的字符串的字符大小写
NF 数据文件中的字段总数
NR 已处理的输入记录数
FNR 当前数据文件中的数据行数
OFMT 数字的输出格式，默认值为%.6 g
RLENGTH 由match函数所匹配的子字符串的长度

  • ENVIRON

可以通过 ENVIRON 来获取 shell 中任何环境变量的值，以供 gawk 程序使用。

  • NF

当不知记录有多少个字段，NF 变量可以用来指定最后一个数据字段。

FNR 变量的值在 gawk 处理第二个数据文件时被重置了，而 NR 变量则在处理第二个数据文件时继续计数。

4.4 流程控制与 printf 格式化

流程控制

  • if 语句

  • do-while 语句：先执行循环体再判断条件，循环体至少执行一次

printf 格式化

gawk 使用 printf 命令实现格式化，命令格式：printf "%[modifier]control-letter ...", var1, var2 ...

控制字母 说明
c 将一个数作为ASCII字符显示
d 显示一个整数值
i 显示一个整数值（跟d一样）
e 用科学计数法显示一个数
f 显示一个浮点值

除了控制字母外，还有3种修饰符可以用来进一步控制输出。

  • width：指定了输出字段最小宽度的数字值。如果输出短于这个值，printf 会将文本右对齐，并用空格进行填充。如果输出比指定的宽度还要长，则按照实际的长度输出。
  • prec：指定了浮点数中小数点后面位数，或者文本字符串中显示的最大字符数。
  • -（减号）：采用左对齐（默认右对齐）。
