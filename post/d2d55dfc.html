一、JVM 与性能排查

技能点 模块 类 / 文件 关键方法 面试话术要点
自定义类加载器 + 打破双亲委派 service-doc classloader/EncryptedClassLoader.java loadClass() 优先自加载 com.zeus.template.*；findClass() XOR 解密 重写 loadClass 而非 findClass 才是打破双亲委派；类隔离的证明是 instanceof false（见单测）
类隔离单测 service-doc src/test/java/com/zeus/template/HelloTemplate.java + EncryptedClassLoaderTest 双加载器加载同名类，c1 != c2 且互不 instanceof 双亲委派 vs 打破；Tomcat WebappClassLoader 的对照
对象内存布局（JOL） service-doc EncryptedClassLoaderTest.printObjectLayout() ClassLayout.parseInstance(doc).toPrintable() MarkWord 8B + KlassPointer 4B（压缩指针）；UseCompressedOops 开关对比
GC 日志 / OOM 排查 所有服务 deploy/tomcat/tomcat-tuning.yml（JVM 参数） -Xms2g -Xmx2g -XX:+UseG1GC -XX:+HeapDumpOnOutOfMemoryError G1 vs CMS；MAT 泄漏链；GCeasy 分析入口
压测与性能指标 deploy jmeter/zeus-doc.jmx、verify/verify-infra.sh、docker/grafana/dashboards/ 阶梯加压 100→500→1000→3000 RT/TPS/错误率；梯度压测找拐点

二、并发编程

技能点 模块 类 关键方法 面试话术要点
线程池隔离 + 拒绝策略 service-doc threadpool/ThreadPoolConfig.java 4 个 ThreadPoolTaskExecutor（doc/audit/search-sync/export） 为何隔离（故障/资源/监控/调优）；Abort vs CallerRuns 场景选择；单测覆盖两种策略
动态调参与优雅关闭 service-doc 同上 refresh()；@PreDestroy destroy() + awaitTermination(30s) ThreadPoolExecutor 运行时调参；队列容量不可动态改
TTL 上下文传递 common context/UserContext.java TransmittableThreadLocal + finally clear() ThreadLocal 串号；TTL 在提交时抓快照
CompletableFuture 编排 service-doc service/DocDetailService.java supplyAsync ×3 + allOf().join() + thenApply 串行 150ms → 并行 50ms；单测用”阻塞权限查询证明并行”
读写锁缓存重建 service-doc manager/DocCacheManager.java getOrLoad() 读锁→释放→写锁→Double-Check；tryUpgradeToWriteLock() 演示 读锁不能升级写锁（死锁）；正确做法是释放再抢 + 双重检查
无锁累加 service-doc manager/OnlineUserCounter.java LongAdder + sum() LongAdder 分段累加；sum() 非原子但业务允许最终一致
缓存击穿互斥 service-doc cache/CacheService.java SETNX 抢锁重建 + 自旋等待 缓存三兄弟；布隆过滤器防穿透、随机 TTL 防雪崩
MQ 幂等 service-doc manager/MessageIdempotentHandler.java checkAndMark() + rollback() SETNX + TTL 7d；失败回滚允许重试

三、MySQL 深度

技能点 模块 类 / 文件 关键方法 面试话术要点
慢 SQL 插件 service-doc plugin/SqlCostInterceptor.java 拦截 Executor.query/update，提取实参，>1000ms error 上报 四大核心对象；invocation.proceed() 责任链；单测含实参提取断言
分库分表 service-doc resources/application-sharding.yml doc_history 按 doc_id % 4 分库 + created_at 月份分表 分片算法 MOD/INTERVAL；路由与归并；游标分页案例
主从复制 deploy docker/docker-compose.yml（mysql8 + mysql-slave）、sql/05_master_slave_init.sql、sql/slave-init/01_slave_setup.sh GTID 模式；dump 快照 + MASTER_AUTO_POSITION=1 GTID vs 位点；主从延迟；Slave_IO/SQL_Running 排查
读写分离路由 service-file config/MasterSlaveRoutingDataSource.java + DataSourceRouteAspect.java AbstractRoutingDataSource + @ReadOnly 注解 + 方法名约定 切面 @Order 必须先于事务；从库宕机回退主库；强一致走主库
连接池 各服务 application.yml（HikariCP） maximum-pool-size=50/200、leak-detection-threshold=2000 池大小与 MySQL max_connections 关系；泄漏检测原理
批量写 service-doc 版本保存（DocVersionService） jdbcTemplate.batchUpdate() 500 条/批 禁止 for 循环单条插入；batch 减少网络往返

四、Redis 与缓存架构

技能点 模块 类 关键方法 面试话术要点
三级缓存 service-doc cache/CacheService.java getDocContent()：Caffeine → Redis → MySQL 回填 L1/L2/L3 分层理由；热点降级（QPS>100 只查 L1+L2）
缓存三兄弟 service-doc 同上 + common BloomFilterUtil 布隆防穿透、SETNX 防击穿、随机 TTL 防雪崩 三者的区别与应对方案（面试必问）
