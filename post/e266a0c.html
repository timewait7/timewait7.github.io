TypeScript 快速上手

Posted on 2026-06-09 In 开发工具 Word count in article: 993 Reading time ≈ 4 mins.

TypeScript 用户管理服务

本项目专为 Java 开发者快速上手 TypeScript 设计。通过一个完整的用户管理服务，展示了 TypeScript 在日常后端开发中最常用的特性（接口、类、泛型、枚举、联合类型、装饰器、异步/等待、类型守卫等）。代码可以直接运行，你也可以在此基础上模仿并扩展。

定位说明：本文是面向 Java 开发者的 TypeScript 语言入门教程，不属于 AI 专题内容。它是阅读本站 TypeScript 实现的 MCP/Agent 项目（如 mini-cc、weathermate-mcp、ticket-agent-mcp）的语言前置。

项目背景

  • 目标：帮助 Java 背景的开发者理解 TypeScript 的核心语法与设计模式。
  • 场景：内存用户管理服务（模拟数据库 CRUD），提供用户创建、更新、查询、删除等能力。
  • 技术栈：TypeScript + Node.js（使用 ES 模块）。

快速启动

看到控制台输出用户操作日志和结果即表示运行成功。

环境依赖

配置说明

TypeScript 配置（tsconfig.json）

关键配置项：

配置项 值 说明
target ES2020 编译目标版本，支持 async/await
module NodeNext 使用 Node.js 原生 ES 模块
moduleResolution NodeNext 模块解析策略
outDir ./dist 编译输出目录
rootDir ./src 源码根目录
strict true 启用所有严格类型检查选项
experimentalDecorators true 启用装饰器语法
esModuleInterop true 简化 CommonJS 模块导入

包脚本（package.json）

脚本 命令 说明
npm run build tsc 将 TypeScript 编译到 dist/
npm start node dist/index.js 运行编译后的 JavaScript
npm run dev tsx src/index.ts 直接运行 TypeScript（开发模式）

运行方式

开发模式

  • 使用 tsx 直接执行 .ts 文件，无需编译。
  • 支持热更新（保存后手动重新运行，或搭配 nodemon 自动重启）。

学习路径建议

  1. 先运行项目，观察输出与日志。
  2. 对照 index.ts 中的演示代码，逐一理解每个特性。
  3. 尝试修改或扩展：
    • 添加新的字段（如 phone）。
    • 增加 @validate 装饰器进行参数校验。
    • 将内存存储改为文件存储（使用 fs/promises）。
  4. 参考项目结构应用到自己的实际 TypeScript 项目中。

扩展

  1. 添加 @validate 装饰器，在方法执行前校验参数（如年龄>0）。
  2. 在 UserRepository 中使用 泛型约束（例如 Repository<T extends { id: ID }>）。
  3. 将内存存储改为 文件存储（使用 fs.promises），体验 Node.js 生态。
  4. 使用 Pick, Omit, Readonly 等内置工具类型，定义新的视图类型。
