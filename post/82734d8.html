Shell 编程入门与实战

Posted on 2024-12-13 In 部署运维 Word count in article: 5.7k Reading time ≈ 21 mins.

Shell 入门

脚本骨架

变量

  • 定义 name=alice；引用 $name 或 ${name}；拼接 "Hello ${name}!"
  • 环境变量：$PATH、$HOME 等；export VAR=value 导出给子进程
  • 命令替换：today=$(date +%y%m%d) 把 date 的输出赋给变量（反引号 `date` 等价，推荐 $()）
  • 算术运算：$((3 * 5))；((x = x + 1)) 可用于赋值
  • 脚本参数：$1、$2 位置参数，$# 参数个数，$0 脚本名，$? 上一条命令退出码
  • 特殊技巧：IFS=$'\n' 把字段分隔符改为换行，for 遍历带空格的行时很有用

条件判断

  • 数值比较：[ n1 -gt n2 ]——-gt 大于、-lt 小于、-eq 等于、-ge 大于等于、-le 小于等于、-ne 不等于
  • 字符串比较：[ "$str" = "abc" ] 相同、!= 不同、-z "$str" 为空、-n "$str" 非空（比较时变量加引号，防空值报错）
  • 文件判断：[ -f file ] 是普通文件、[ -d dir ] 是目录、[ -e path ] 存在、[ -s file ] 非空、[ -w file ] 可写、[ -x file ] 可执行、[ file1 -nt file2 ] file1 比 file2 新
  • [[ ]] 是 bash 的扩展写法：支持 &&、|| 和 =~ 正则匹配，日常写 bash 脚本推荐优先用 [[ ]]（注意它只存在于 bash，sh 下没有）

常见陷阱

  1. 赋值等号两边不能有空格：name = "alice" 会被解析成运行 name 命令
  2. 变量引用不加大引号：值含空格或为空时命令会被拆散，[ "$str" = "abc" ] 而不是 [ $str = abc ]
  3. [ ] 内部各项必须用空格隔开：[ "$a" -eq 1] 会报错（1] 粘连）
  4. 字符串比较用 =，数值比较用 -eq，不能混用
  5. 空格敏感的还有 [ ] 和 then：if [ x ]; then 与分成两行等价
  6. 脚本执行权限：bash script.sh 不需要 x 权限；./script.sh 需要 chmod +x 且 shebang 正确
  7. 调试脚本：bash -x script.sh 逐行打印执行过程；bash -n script.sh 只查语法错误

附录：脚本编写规范

本文脚本中反复出现以下良好实践，编写新运维脚本时可直接套用。

错误处理：set -euo pipefail

  • set -e：任一命令返回非零立即退出（2.4 deploy-java.sh 已使用，可升级为完整版）
  • set -u：引用未定义变量直接报错，拼写错误无处遁形
  • set -o pipefail：管道中前面命令失败时整体仍算失败——典型场景是 grep 无匹配返回非零（见 2.3 log-analyzer.sh 中 grep -c 的处理注释）
  • 注意：开启 set -e 后，需要捕获退出码的场景要用 cmd; ret=$? 先存后判——$? 只保留上一条命令的退出码，直接连用会丢失前面的结果（见 2.2 服务健康检查 中 process_ok=$? 的写法）

日志规范：时间戳 + 级别

统一 [级别] 时间 消息 格式，方便按级别 grep 检索：

  • 彩色输出可参考 2.4 deploy-java.sh 的 log_info/log_warn/log_error（重定向到文件时退化为纯文本）
  • 持续运行的脚本（如 2.6 monitor-resources.sh）用 tee -a 同时输出到屏幕并落盘

参数校验：dry-run 与必填校验

  • **危险操作提供 --dry-run**：只预览将要执行的动作、不真正执行，确认无误后再去掉该选项（见 1.2 / 2.1 批量重命名）
  • 必填参数显式校验：先判断再退出，附用法提示
  • 环境变量必填校验：用参数扩展直接报错，杜绝空值继续运行（见 2.5 MySQL 备份）
  • 可选参数默认值兜底：LOG_FILE="${1:-application.log}"（见 2.3 日志分析、2.7 批量日志处理）

附录：Vim 速查

Vim 的学习重点是”先记住常用键，再在编辑中自然扩展”。以下速查表覆盖日常编辑的 90% 场景。

基本操作

命令 说明
i / a 光标前 / 后插入
o / O 当前行后 / 前插入一行
esc 返回 Normal 模式（退出编辑）
:q / :q! / :wq 退出 / 强制退出 / 保存并退出
u / ctrl+r 撤销 / 重做
:set number / :set nonumber 显示 / 取消行号
gg / G / :n 跳到第一行 / 最后一行 / 第 n 行

选择、剪切、拷贝

d 删除、c 剪切（删除并进入编辑）、v 选择、y 拷贝，后面跟移动命令即可作用到对应范围。dd 删整行、yy 拷整行；x 删当前字符、X 删前一个字符；p 粘贴到光标后（P 粘贴到光标前）。

移动 剪切 选择 删除 拷贝
0（行头） c0 v0 d0 y0
$（行尾） c$ v$ d$ y$
w（下一单词） cw vw dw yw
b（单词开头） cb vb db yb
e（单词结尾） ce ve de ye
gg / G（文首 / 文尾） cgg / cG vgg / vG dgg / dG ygg / yG

搜索与替换

命令 说明
/keyword / ?keyword 向下 / 向上搜索
n / N 下一个 / 上一个匹配项
* / # 向下 / 向上搜索光标所在单词
:set hlsearch / :nohlsearch 开启 / 关闭匹配高亮
/\<keyword\> 全词匹配搜索
:set ignorecase / :set noignorecase 忽略 / 区分大小写（默认区分）
/\d / /^keyword 搜索含数字的行 / 以 keyword 开头的行

搜索并替换（格式为 [范围]s/旧/新/选项）：

命令 说明
:%s/foo/bar/g 全文替换
:%s/foo/bar/gc 替换前逐个确认
:%s/foo/bar/gi 忽略大小写
:10,20s/foo/bar/g 只在 10~20 行范围内替换
:.,$s/foo/bar/g 从当前行到文件末尾替换
:%s/foo//g 删除所有匹配文本

大小写切换

命令 说明
gu + 移动 范围内变小写（gul 当前字符、guu 当前行）
gU + 移动 范围内变大写（gUl 当前字符、gUU 当前行）

实用技巧

命令 说明
:% 选中全文
:%d / :%y 删除全文 / 拷贝全文到寄存器
:%y+ 拷贝全文到系统剪贴板（+ 是剪贴板寄存器）
ggVGy 拷贝全文到寄存器
dt" 删除直到下一个双引号（d + t"：到字符 " 之前为止）
y2/foo 拷贝两个 foo 之间的内容
. 重复上一次命令（如 3x 表示删除 3 个字符）
f<char> / t<char> 跳到下一个 <char> / 下一个 <char> 的前一个字符
