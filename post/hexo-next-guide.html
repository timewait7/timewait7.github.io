6. 博客布局

本站的体系是「文章 + 导航页」双轨：

  • 文章（source/_posts/）：真实内容，计入文章列表，URL 为 /post/<短码>.html
  • 导航页（source/docs/、source/docs/nav/）：分类索引，layout: page，不计入文章列表，URL 等于物理路径（/docs/nav/java-nav.html）

6.2 四层导航菜单

6.2.1 菜单结构

_config.next.yml 的 menu: 段支持任意层级的树形嵌套，每层节点用 default: 指定本节点的页面路径，叶子节点直接给文章路径：

6.2.2 相对路径规则（关键）

每个节点的配置值 = 从父节点页面出发，到目标页面的相对路径：

节点 父页面 目标页面 配置值
顶级 Docs 无 /docs/ /docs/（绝对路径）
第二层 /docs/ /docs/nav/xxx.html nav/xxx.html
第三层 /docs/nav/xxx.html 同目录的另一导航页 ../yyy-nav.html
叶子（文章） /docs/nav/xxx.html /post/xxx.html ../../../post/xxx.html

规则记忆法：第二层从 /docs/ 进入 nav/ 目录；导航页互跳用 ../；文章目录 /post/ 与 /docs/nav/ 互不相干，需向上三级（docs/nav/ → docs/ → 根）再进入 post/。

6.2.3 图标

菜单图标使用 FontAwesome：|| fa fa-xxx。分类用语义化图标（书、代码、数据库、服务等），文章统一 fa fa-file-code。

8. 日常维护

新增一篇博文：

  1. 在 source/_posts/ 下新建 Markdown 文件，按 6.1.1 模板填写 front-matter
  2. 在所属分类的导航页（source/docs/nav/*.md）表格中加入文章行
  3. 在 _config.next.yml 的 menu: 对应节点下追加叶子条目（值用 ../../../post/<短码>.html || fa fa-file-code）
  4. hexo clean && hexo generate，本地预览确认无误
  5. hexo deploy 发布

新增一个分类导航页：

  1. 创建 source/docs/nav/<名字>-nav.md（按 6.1.2 模板）
  2. 在上级导航页加入链接
  3. 在 menu: 中加入对应节点。
