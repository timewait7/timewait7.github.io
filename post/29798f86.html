ls / cd / pwd

练习主题：ls、cd、pwd — 目录浏览与路径切换

常用选项清单：

命令 核心选项 说明 使用场景
ls -l 长格式显示（权限、大小、时间） 查看文件详情
-a 显示所有文件（含.开头的隐藏文件） 查看隐藏配置
-h 人类可读大小（K、M、G） 看文件大小时用
-t 按修改时间排序 找最新文件
-r 反向排序 与-t连用找最旧文件
常用组合 ls -lah 显示所有文件 + 人类可读大小 + 详细信息 每天必用
ls -lt 按时间排序显示 查看最新文件
ls -ltr 按时间倒序（最旧的在最上面） 查看最旧文件
cd ~ 回到用户主目录 cd ~
- 回到上一个目录 cd -
.. 上级目录 cd ../..
pwd -P 显示物理路径（不显示符号链接） 确认真实路径
-L 显示逻辑路径（默认） —

cp / mv / rm

练习主题：cp（复制）、mv（移动/重命名）、rm（删除）—— 安全操作与批量处理

常用选项清单：

命令 核心选项 说明 使用场景
cp -i 交互确认（覆盖前询问） 防止cp覆盖重要配置文件，强烈建议设别名
-u 只复制更新的文件（源文件比目标新才复制） 增量部署：只覆盖改动的静态资源/class文件，极大节省时间
-r / -a 递归复制目录（-a保留权限、时间戳） 备份整个项目目录
-b 覆盖前自动备份目标文件（生成~后缀） 覆盖前留个心眼，出错了能快速恢复
mv -i 交互确认（覆盖前询问） 移动/重命名时防止误覆盖
-u 只移动更新的文件 合并两个目录时，只更新旧文件
rm -i 交互确认（逐个询问删除） 救命选项，防止删错文件
-r 递归删除目录 删除整个文件夹（极度危险，慎用）
-- 结束选项标志 删除以 - 开头的古怪文件名（如 -file.txt）

find + xargs

练习主题：find + xargs — 批量查找与处理

核心选项清单：

命令/组合 核心用法 说明 生产场景
find -name "*.log" 按文件名查找（通配符） 查找所有日志文件
-type f / -type d 按类型（文件/目录） 只找文件，不找文件夹
-size +100M 按大小筛选 找出大文件清理磁盘
-mtime -7 / +7 按修改时间（7天内/超过7天） 清理旧日志
-exec {} \; 对每个结果执行命令 逐个处理，慢但安全
xargs xargs -n1 每次传1个参数 配合rm安全删除
xargs -P 4 并行执行（4个进程） 批量压缩/转换，提速
组合 find ... -print0 | xargs -0 处理含空格/换行的文件名 生产环境必用，防文件名里有空格炸裂

find + -exec

练习主题：find + -exec — 查找并执行操作

核心选项清单：

用法 说明 生产场景
find ... -exec {} \; 对每个找到的文件依次执行命令（分号结尾，需要转义） 逐个处理，安全可靠
find ... -exec {} + 将找到的文件批量传给命令执行（加号结尾，一次执行） 批量操作，效率更高
find ... -ok {} \; 与 -exec 类似，但每步都询问确认 危险操作前先演练
! -exec 对不匹配条件的文件执行命令 查找“不包含”特定内容的文件

tar / gzip / zip

练习主题：tar / gzip / zip — 打包压缩三件套

核心选项清单：

格式 打包（创建） 解包（解压） 查看内容 生产场景
.tar.gz tar -czvf 包名.tar.gz 源目录/ tar -xzvf 包名.tar.gz tar -tzvf 包名.tar.gz 最常用，发布Java/Go/Node应用
.tar.bz2 tar -cjvf 包名.tar.bz2 源目录/ tar -xjvf 包名.tar.bz2 tar -tjvf 包名.tar.bz2 压缩率更高，适合归档大文件
.zip zip -r 包名.zip 源目录/ unzip 包名.zip -d 目标目录/ unzip -l 包名.zip 跨平台（Windows/Linux通用）
  • tar -czvf = Create Zip Verbose File（创建压缩包，用gzip）
  • tar -xzvf = EXtract Zip Verbose File（解压）

补充选项：

选项 说明
-C 解压时指定目标目录（tar -xzvf 包.tar.gz -C /target/）
--exclude 打包时排除特定文件/目录
-d gzip -d = 解压 .gz 文件

ln

练习主题：ln — 软链接（符号链接）与硬链接

核心选项清单（今天只记这2个）：

命令 说明 生产场景
ln -s 源文件 链接名 创建软链接（符号链接），类似Windows快捷方式 版本切换（JDK）、统一日志路径、避免重复部署
ln 源文件 链接名 创建硬链接，指向同一个inode（数据块） 文件备份、镜像文件（不占额外空间）

一句话区别：

  • 软链接：存的是路径，原文件删了就失效（ls -l 显示 -> 指向）
  • 硬链接：存的是数据块地址，原文件删了还能用（ls -li 看到相同inode号）

chmod / chown / chgrp

练习主题：修改文件权限、所有者、所属组

核心选项清单：

命令 核心用法 说明 生产场景
chmod chmod 755 file 数字模式：rwx 用数字表示 给脚本加执行权限
chmod u+x file 符号模式：给用户加执行权限 精确控制权限
chmod -R 755 dir/ 递归修改目录下所有文件 批量修复权限
chmod --reference=模板 目标 参考另一个文件的权限 快速复制权限
chown chown user:group file 同时修改所有者和组 部署时修正文件归属
chown -R user:group dir/ 递归修改整个目录 批量修正归属
chown user file 只修改所有者 单个文件归属调整
chgrp chgrp group file 只修改所属组 调整文件组权限

权限数字速查：

  • 4 = 读（r）
  • 2 = 写（w）
  • 1 = 执行（x）
  • 755 = 用户：rwx（7），组：r-x（5），其他：r-x（5）
  • 644 = 用户：rw-（6），组：r–（4），其他：r–（4）

df / du / lsblk

练习主题：查看磁盘使用情况、目录大小、块设备信息

核心选项清单：

命令 核心用法 说明 生产场景
df df -h 人类可读格式显示磁盘分区使用 查看磁盘整体使用率
df -i 显示 inode 使用情况 inode 满导致无法创建文件时排查
df -hT 显示文件系统类型 确认分区格式（ext4/xfs等）
du du -sh * 查看当前目录下每个子项的总大小 最常用：找大文件夹
du -h --max-depth=1 显示一级子目录大小 逐层定位大文件位置
du -sh 显示当前目录总大小 快速了解目录占用
lsblk lsblk -f 显示块设备和文件系统 查看磁盘分区挂载情况
lsblk -l 列表格式显示 机器可读格式

mount / umount

练习主题：挂载文件系统、卸载、查看挂载信息

核心选项清单

命令 核心用法 说明 生产场景
mount mount 查看当前所有挂载点 查看已挂载的文件系统
mount -t ext4 /dev/sdb1 /mnt 挂载指定分区到目录 挂载新硬盘
mount -o ro /dev/sdb1 /mnt 只读挂载 数据恢复、安全访问
umount umount /mnt 卸载指定挂载点 安全移除硬盘
umount -l /mnt 懒惰卸载 设备忙时强制卸载
/etc/fstab 查看配置文件 开机自动挂载配置 确保硬盘重启后自动挂载
