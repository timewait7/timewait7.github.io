ln

练习主题：ln — 软链接（符号链接）与硬链接

核心选项清单（今天只记这2个）：

命令 说明 生产场景
ln -s 源文件 链接名 创建软链接（符号链接），类似Windows快捷方式 版本切换（JDK）、统一日志路径、避免重复部署
ln 源文件 链接名 创建硬链接，指向同一个inode（数据块） 文件备份、镜像文件（不占额外空间）

一句话区别：

  • 软链接：存的是路径，原文件删了就失效（ls -l 显示 -> 指向）
  • 硬链接：存的是数据块地址，原文件删了还能用（ls -li 看到相同inode号）

chmod / chown / chgrp

练习主题：修改文件权限、所有者、所属组

核心选项清单：

命令 核心用法 说明 生产场景
chmod chmod 755 file 数字模式：rwx 用数字表示 给脚本加执行权限
chmod u+x file 符号模式：给用户加执行权限 精确控制权限
chmod -R 755 dir/ 递归修改目录下所有文件 批量修复权限
chmod --reference=模板 目标 参考另一个文件的权限 快速复制权限
chown chown user:group file 同时修改所有者和组 部署时修正文件归属
chown -R user:group dir/ 递归修改整个目录 批量修正归属
chown user file 只修改所有者 单个文件归属调整
chgrp chgrp group file 只修改所属组 调整文件组权限

权限数字速查：

  • 4 = 读（r）
  • 2 = 写（w）
  • 1 = 执行（x）
  • 755 = 用户：rwx（7），组：r-x（5），其他：r-x（5）
  • 644 = 用户：rw-（6），组：r–（4），其他：r–（4）

sort / uniq / wc

练习主题：sort / uniq / wc — 排序、去重与统计

核心选项清单：

命令 核心选项 说明 生产场景
sort -n 按数字排序（而不是字典序） 排序响应时间、状态码
-r 反向排序（从大到小） 找最大/最频繁的值
-k n 按第 n 列排序 按日志中的某一列排序
-t ':' 指定分隔符 处理 CSV、passwd 等文件
-u 去重排序（等价于 sort | uniq） 快速去重
uniq -c 统计每个值出现的次数 最常用，统计频率
-d 只显示重复的行 找出重复数据
-u 只显示出现一次的行 找出唯一数据
wc -l 统计行数 统计日志条数
-w 统计单词数 统计文本量
-c 统计字节数 文件大小校验

核心组合：sort | uniq -c | sort -rn — 先排序，再统计次数，最后按次数从大到小排序。这是统计“TOP N”的黄金命令。

PS：单独使用 uniq -c 统计频率是不准确的，uniq 只合并相邻的行，如果相同的行被隔开了，会被当作不同的条目统计。所以 sort 之后再用 uniq -c 才能正确统计频率。

核心选项清单：

命令 核心选项 说明 生产场景
cut -d ':' 指定分隔符（默认是Tab） 处理CSV、passwd等分隔符文件
-f 1,3 提取第1、3列 提取指定字段

sed

练习主题：sed 替换 — 文本批量编辑

核心选项清单：

命令 核心选项/用法 说明 生产场景
sed 's/old/new/g' 全局替换，替换每一行中所有匹配 批量改配置、改日志格式
's/old/new/' 只替换每行第一个匹配 谨慎替换，避免误伤

'/pattern/d' 删除包含匹配模式的行 删除注释行、空行、敏感信息行
'2,5d' 删除第2到第5行 删除文件头部/尾部指定行
'/pattern/,/pattern/d' 删除从匹配1到匹配2之间的所有行 删除配置块（如删除整个server块）
'2,5p' 打印第2到第5行（需配合 -n） 提取日志片段
'/pattern/p' 打印匹配行（需配合 -n） 快速提取特定内容
'N' 读取下一行并追加到模式空间（多行处理） 将多行堆栈合并为一行
's/\n//' 删除换行符（合并行） 将多行日志合并为单行
'n' 跳过当前行，读取下一行 处理隔行数据

awk

练习主题：awk 基础 — 字段提取与内置变量

核心概念：

awk 的核心模型：逐行读取 → 按分隔符切分 → 用 $1、$2… 访问每一列

概念 说明 示例
$0 整行内容 {print $0} = 打印整行
$1 第1列 {print $1} = 打印第一列
$2…$N 第N列 {print $3} = 打印第三列
$NF 最后一列（NF是列数变量） {print $NF} = 打印最后一列
NF 当前行的列数 {print NF} = 打印列数
NR 当前行号（从1开始） {print NR, $1} = 行号+第一列
FS 输入分隔符（默认空格） -F: 或 BEGIN{FS=":"}
OFS 输出分隔符（默认空格） BEGIN{OFS=","}
BEGIN{} 读取文件前执行一次 设置变量、打印表头
END{} 读取文件后执行一次 输出统计结果

核心记忆：awk '{print $1, $2}' = 打印第1列和第2列，默认空格分隔。

练习主题：awk 条件判断与数组统计

核心概念清单：

概念 说明 示例
条件过滤 只处理满足条件的行 awk '$3=="ERROR"'
比较运算 ==、!=、>、<、>=、<= awk '$4>300'
逻辑运算 &&（与）、`
if-else 分支判断 awk '{if($3=="ERROR") print "严重"; else print "正常"}'
数组 关联数组，下标可以是任意值 count[$1]++
遍历数组 for(key in arr) for(k in count) print k, count[k]
去重统计 数组累加 统计IP出现次数、各状态码数量
求和/平均 数组累加 + 最终计算 统计总耗时、平均耗时

核心记忆：awk 数组是关联数组（类似Java的Map/Python的字典），下标可以是字符串。

模式 含义 生产场景

CLI&Vim 快捷操作

Posted on 2026-08-25 Word count in article: 1.8k Reading time ≈ 6 mins.

CLI

Linux 默认的 CLI（Bash/Zsh）使用的是 Emacs 风格的快捷键，所有操作都能在主键盘区完成，手完全不用离开打字位。

光标移动（告别方向键）

快捷键 作用 记忆法（谐音/联想）
Ctrl + A 跳到行首 A = Ahead（开头）
Ctrl + E 跳到行尾 E = End（结尾）
Alt + B 向左跳一个单词（单词首） B = Back（向后）
Alt + F 向右跳一个单词（单词尾） F = Forward（向前）
Ctrl + XX 在当前位置和行首之间来回跳 （用于临时看开头）

Mac 用户：Mac 的 Alt 键默认不生效，需要开启 Terminal -> Settings -> Keyboard -> 勾选 “Use Option as Meta key”，或者将 Alt 替换为 Esc 键（先按 Esc 再按 B/F）。

命令修改（删除与撤销）

方向键只能移到错误字符处按 Delete，太慢了。直接用以下组合按词删除或整行删除：

快捷键 作用 使用场景
Ctrl + U 删除光标前的所有内容（剪切） 输错密码或不想要前半段了
Ctrl + K 删除光标后的所有内容（剪切） 保留开头，删掉后面
Alt + Backspace 删除光标前的一个单词 删掉刚输错的参数
Alt + D 删除光标后的一个单词 删掉光标后面的单词
Ctrl + W 删除光标前的一个路径/大块字符 比 Alt+Backspace 切得更狠
Ctrl + Y 粘贴（黏贴）刚才 Ctrl+U/K/W 剪切的文字 相当于“剪切板”粘贴

💡 救命的撤销：Bash 默认没有 Ctrl+Z 撤销，但你可以按 **Ctrl + _**（下划线）来撤销上一次编辑操作。

命令历史（告别上下键翻找）

按几十次 ↑ 方向键找旧命令是最大的时间杀手。

快捷键 作用 说明
Ctrl + R 反向历史搜索（最核心） 输入关键字，实时匹配历史命令。按多次 Ctrl+R 会在匹配项间跳转。
Ctrl + P 上一条 等同于 ↑ ，但手不用移开主键区。

进程控制（命令行常用）

快捷键 作用 说明
Ctrl + C 强制中断当前命令/进程 卡住时按（发送 SIGINT）
Ctrl + D 退出终端 或 发送 EOF 相当于输入 exit；在命令行中空按会注销会话
Ctrl + Z 挂起当前进程（放到后台） 误操作大文件打开时，按 Z 挂起，再用 bg 放后台跑
Ctrl + L 清屏 等同于输入 clear，屏幕瞬间清爽

高阶彩蛋

这几个属于“不用记，但用一次就回不去”的技巧：

  • Alt + .（点号）：粘贴上一条命令的最后一个参数。
    • 场景：刚 cat /etc/nginx/nginx.conf 看完，想用 vim 改它。输入 vim，然后按 Alt + .，路径自动补全。
  • **Alt + 数字键 + 快捷键**：重复执行操作。
    • 场景：按 Alt + 3 + Alt + D，会向后删除 3 个单词。
  • **!!**：代表上一条完整命令（虽不是快捷键，但极常用）。
    • 场景：apt install nginx 权限不够，直接输入 sudo !! 回车，完美。

iTerm2 独门“超能力”

选中即复制，右键即粘贴（省去 Cmd+C/V）

  • 设置：Preferences -> General -> Selection -> 勾选 **Copy to pasteboard on selection**。
  • 用法：鼠标选中任何文字，自动复制到剪贴板；点击鼠标中键（滚轮按下去）或 Shift + 右键，直接粘贴。手完全不用去够 Cmd 键。

强大的“智能补全” (Cmd + ;)

  • 输入前半截命令，按 Cmd + ;（分号键），iTerm2 会弹出一个下拉框，模糊匹配你的历史命令和目录结构。想找几天前一串很长的 docker run... 命令？敲几个字母，按这个组合，比 Ctrl+R 搜得还直观（可视界面）。

粘贴历史 (Cmd + Shift + H)

  • 按 **Cmd + Shift + H**，会弹出你最近复制过的所有文本片段（不仅仅是命令行里的，系统全局复制过的都在）。找密码、找路径、找刚才复制的一长串 JSON，极其方便。

命令“即输即显”极速定位

  • 按住 Cmd 键，鼠标点击命令行中的任意路径/文件名，iTerm2 会自动识别并尝试打开它（ls 出来的文件，按住 Cmd 点击就用默认编辑器打开了，非常酷）。
  • 按住 Shift 键，鼠标框选文本，可以进行矩形块状选择（对于复制表格日志非常有用）。

切换标签页和分屏

  • 切换上一个/下一个标签页：Cmd + 左方向键 和 Cmd + 右方向键。（如果嫌手要挪到方向键，可以改为 Cmd + Shift + [ 和 Cmd + Shift + ]，和 Chrome 浏览器逻辑一致）。
  • 垂直/水平分屏（把同一个窗口切成两块独立终端：左边用 vim 改代码，右边用命令行执行编译，不用切来切去）：
    • Cmd + D：垂直左右分屏。
    • Cmd + Shift + D：水平上下分屏。

1. 系统信息与性能排查

1.1 高频命令

命令 用途
uptime 查看系统负载、运行时长、登录用户数
top -c / htop 实时查看进程 CPU、内存占用，-c 显示完整命令行
vmstat 1 5 查看 CPU、内存、IO、上下文切换，每秒 1 次共 5 次
iostat -xz 1 查看磁盘 IO 使用率、等待时间、吞吐量
mpstat -P ALL 1 查看每个 CPU 核心的使用率
free -h 查看内存和 Swap 使用情况
sar -n DEV 1 查看网卡流量、错误包
dmesg | tail -20 查看内核日志，判断硬件或 OOM 问题
lscpu / lsblk 查看 CPU 架构 / 块设备信息
nproc 查看 CPU 核数

1.2 生产实践案例

场景：业务反馈服务器卡顿，页面打开缓慢。

处理结果：发现是某个定时任务与业务高峰叠加，临时降低任务频率，并优化了代码中的死循环。

2. 文件与磁盘管理

2.1 高频命令

命令 用途
df -hT 查看磁盘分区使用率及文件系统类型
du -sh /* 统计根目录下各目录大小，快速定位大目录
du -h --max-depth=1 /var 按层级查看目录占用
ls -lht /var/log 按时间倒序列出文件大小
find / -type f -size +100M -mtime -7 查找最近 7 天修改的 100M 以上文件
stat /path/file 查看文件详细属性、时间戳
lsof +L1 查找已被删除但仍被进程占用的文件
lsattr / chattr 查看/设置文件隐藏属性，防止误删
rsync -avz src/ dest/ 高效同步文件/目录
tar -czvf backup.tar.gz /path 打包压缩
tar -xzvf backup.tar.gz -C /target 解压到指定目录
dd if=/dev/zero of=test.img bs=1M count=100 生成测试文件或测试磁盘写速度
blkid / mount 查看块设备 UUID 和挂载信息
fdisk -l 查看磁盘分区表

2.2 生产实践案例

场景：监控告警服务器磁盘使用率达到 95%。

处理结果：日志文件被 logrotate 正常切割，磁盘使用率降至 60%，并配置了告警阈值。

3.1 高频命令

命令 用途

处理结果：防火墙规则遗漏导致，放行后服务恢复。后续将防火墙配置纳入变更审核流程。

命令 用途
