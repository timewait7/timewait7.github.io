ls/cd/pwd

练习主题：ls、cd、pwd — 目录浏览与路径切换

常用选项清单（记住3个核心组合即可）：

命令 核心选项 说明 使用场景
ls -l 长格式显示（权限、大小、时间） 查看文件详情
-a 显示所有文件（含.开头的隐藏文件） 查看隐藏配置
-h 人类可读大小（K、M、G） 看文件大小时用
-t 按修改时间排序 找最新文件
-r 反向排序 与-t连用找最旧文件
常用组合 ls -lah 显示所有文件 + 人类可读大小 + 详细信息 每天必用
ls -lt 按时间排序显示 查看最新文件
ls -ltr 按时间倒序（最旧的在最上面） 查看最旧文件
cd ~ 回到用户主目录 cd ~
- 回到上一个目录 cd -
.. 上级目录 cd ../..
pwd -P 显示物理路径（不显示符号链接） 确认真实路径
-L 显示逻辑路径（默认） —

cp/mv/rm

练习主题：cp（复制）、mv（移动/重命名）、rm（删除）—— 安全操作与批量处理

常用选项清单（今天只死磕这6个，其他的不用记）：

命令 核心选项 说明 使用场景
cp -i 交互确认（覆盖前询问） 防止cp覆盖重要配置文件，强烈建议设别名
-u 只复制更新的文件（源文件比目标新才复制） 增量部署：只覆盖改动的静态资源/class文件，极大节省时间
-r / -a 递归复制目录（-a保留权限、时间戳） 备份整个项目目录
-b 覆盖前自动备份目标文件（生成~后缀） 覆盖前留个心眼，出错了能快速恢复
mv -i 交互确认（覆盖前询问） 移动/重命名时防止误覆盖
-u 只移动更新的文件 合并两个目录时，只更新旧文件
rm -i 交互确认（逐个询问删除） 救命选项，防止删错文件
-r 递归删除目录 删除整个文件夹（极度危险，慎用）
-- 结束选项标志 删除以 - 开头的古怪文件名（如 -file.txt）

nproc 查看 CPU 核数

2.1 高频命令

命令 用途
df -hT 查看磁盘分区使用率及文件系统类型

tar -xzvf backup.tar.gz -C /target 解压到指定目录
dd if=/dev/zero of=test.img bs=1M count=100 生成测试文件或测试磁盘写速度

2.2 生产实践案例

Zeus-Doc-复现学习路线图

Posted on 2026-08-17 In 项目实战 Word count in article: 2.3k Reading time ≈ 8 mins.

目标：把”照着复现项目”变成”系统性技术提升”。核心方法是每个技能块的
四步学习闭环：读 → 写 → 验 → 答。

  • 读：原理资料 + 参考实现（现有文档 + 代码，对照《Zeus-Doc-技能点与代码落点索引》）
  • 写：不抄代码，先遮住参考实现自己写，写不出再看
  • 验：跑实验/单测/验证脚本，让结果说话
  • 答：用面试题自测（《Zeus-Doc-项目面试实战手册》），能讲清楚才算掌握

熟练度定义：了解（能说原理）/ 掌握（能写出代码）/ 熟练（能讲清并答追问）/ 精通（能讲设计取舍与缺陷）。

一、学习闭环总览

铁律：

  1. 每个技能块必须走完四步才算完成，禁止”读完了就当会了”；
  2. “写”时参考实现只允许看接口签名和注释，禁止直接抄方法体（抄了=没练）；
  3. “答”用口头复述（不是默写），对着镜子/录音讲，讲不顺的地方就是没懂的地方；
  4. 每周末做一次”上周技能块总复习”：随机抽 3 个面试题盲答。
